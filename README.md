# PowerShell scripts and modules
This is my collection of scripts and modules that I've created and used as a system administrator. Make sure to analyze and test them before using them.

## Scripts
There are a variety of scripts, including scripts that perform back-up of files, convert EML files to HTML, create Microsoft 365 users, export Windows Server configurations, and more.

## Modules
There are two modules - one that allows you to manage daily to-do lists (**WhatToDo**) and one that allows you to develop custom PowerShell scripts and modules (**PSDev**).

## PowerShell profile
A basic PowerShell profile is included to have a starting point for terminal and workflow customization.
